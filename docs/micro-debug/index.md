# 微服务本地 Debug

> 把运行在 Kubernetes 里的微服务「拉」到本地 IDE 调试的完整实践。

## 这套文档解决什么问题

联调/开发环境的微服务依赖集群内的注册中心、配置中心、消息队列、内网地址和**实例级凭据**。本地进程直接启动通常会遇到：

- 注册地址/端口/路由 tag 不对 → 流量到不了本地
- 配置中心、消息队列的内网端点本机不可达
- 云上靠「实例 RAM 角色」隐式取凭据，本地没有实例元数据服务 → 鉴权失败
- 本地实例沿用 dev 消费组 → 抢消息（安全事故）

插件 `ms-localdebug` 把这些动作固化成 **初始化 → 替换 → 隧道（调试命令）→ 回滚** 四步；「哪些配置 key 要替换、替换成什么、为什么」由**可配置的适配包**表达，不写死在插件里。

## 文档版本

- 插件版本：**v1.0.32**（构建 2026-10-22）

- 其他技术栈：通过「栈描述符 + 适配包」扩展（见第 5 章）

## 能力一览

| 能力 | 入口 | 说明 |
|---|---|---|
| 工具安装 | 工具安装页 | 下载/更新 kubectl、ktctl（版本可选、地址模板可改） |
| 配置向导 | 配置向导页 | 选模板 → 表单填写 → 保存平台配置（密文进 IDE PasswordSafe） |
| 技术栈选择 | 项目配置页「技术栈」下拉 | 默认通用栈；内置组织栈示例；导入模板可直接选用 |
| 初始化配置 | 项目配置页 | 备份项目配置、生成 `.localdebug.*`、改写 application/bootstrap、按模板调整 pom |
| 替换配置 | 项目配置页 | 拉取 nacos 配置、替换中间件参数、生成隧道命令与 JVM 启动参数 |
| 隧道调试 | 调试命令页 | 启动/停止 ktctl connect/mesh/preview 等命令 |
| 回滚配置 | 项目配置页 | 还原文件与 pom，并按描述符清理隧道资源（失败不阻断） |
| 组织前提审计 | 项目配置页告警条 | 未确认项计数、「全部确认」回写 `.localdebug.audit.json` |

## 当前版本限制

> 文档如实标注当前构建的行为，避免「照着文档点却没有效果」。

- **证据门控已启用**：适配包的 `requires` 按 pom 依赖 / 配置键证据判定（ANY）；评估失败 fail-open 并记入 audit。证据范围限项目根（见第 5 章限制）。
- **已支持项目级选栈**：项目配置页「技术栈」下拉写 `.localdebug.json` 的 `stackRef`；初始化/替换/回滚按所选栈执行（默认 = 通用栈；旧项目自动沿用组织示例栈）。
- **示例适配包**对应「阿里云实例角色 + 自建中间件（churchill）」组合；其他中间件请按第 5 章自行编写适配包。
